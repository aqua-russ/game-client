# The Verge — клиент на Unity 6

Онлайн-игра в 3D с механиками Ultima Online; весь контент (карта, модели, звуки, тексты) — свой ([ADR 0015](docs/adr/0015-3d-client.md), [ADR 0014](docs/adr/0014-own-assets-server-numbers.md)). Сервер — форк ModernUO (папка `../../server/ModernUO`), клиент — этот Unity-проект. Сейчас переносим оригинальные механики UO эпохи Renaissance (одна Фелукка, ориентир — русские pre-AoS шарды вроде The Abyss); графика — позже.

## Как запустить

1. Откройте Unity Hub → проект **The Verge** (Unity 6000.6.8f1). Если проекта нет в списке: **Add → Add project from disk** → папка `client/The Verge`.
2. В окне Project откройте `Assets/TheVerge/Scenes/Bootstrap.unity` и нажмите **Play**.
3. Появляется окно входа: адрес сервера, логин и пароль → выбор шарда → список персонажей (создание и удаление) → «в мире». Если окно не появилось — меню **The Verge → Prepare Bootstrap Scene**, затем снова **Play**. Мир в Unity пока не рисуется: его модель проверяется ботом и тестами (`tools/check/all.sh`).

Сервер должен быть запущен — как это сделать, `docs/DEV-ENV.md` §1. Файлы данных классического клиента UO (принадлежат EA, в репозитории их нет) лежат в `remaster/uo-data` — см. `docs/adr/0003-world-data.md`.
