# The Verge — клиент на Unity 6

2D-изометрическая онлайн-игра с механиками Ultima Online. Сервер — форк ModernUO (папка `../../server/ModernUO`), клиент — этот Unity-проект. Сейчас переносим оригинальные механики UO эпохи Renaissance (одна Фелукка, ориентир — русские pre-AoS шарды вроде The Abyss); графика — позже.

## Как запустить

1. Откройте Unity Hub → проект **The Verge** (Unity 6000.6.8f1). Если проекта нет в списке: **Add → Add project from disk** → папка `client/The Verge`.
2. В окне Project откройте `Assets/TheVerge/Scenes/Bootstrap.unity` и нажмите **Play**.
3. Сейчас сцена пустая, а в окне Console появляется строка «Клиент запущен». Старый прототип удалён при аудите (задача 0.9, [ADR 0011](docs/adr/0011-prototype-audit.md)); окно входа появится в задаче 1.16. До этого вход в игру проверяется ботом и тестами (`tools/check/all.sh`).

Для полноценной работы нужна установка классического клиента UO (файлы данных принадлежат EA, в репозитории их нет) — см. `docs/adr/0003-world-data.md`.

## Проверка кода

Код логики пишется через тесты: сначала тест, потом реализация ([ADR 0010](docs/adr/0010-test-first-development.md)).

В Терминале из папки `client/The Verge`: `tools/check/all.sh` — сборка, тесты, правила архитектуры и запуск бота; в конце печатает `ОК` или `ОШИБКА`. С ключом `--unity` ещё проверяется компиляция в Unity (редактор Unity должен быть закрыт). Нужны .NET SDK 10 и инструменты разработчика Xcode (`xcode-select --install`).
