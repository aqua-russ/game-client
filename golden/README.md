# Эталонные логи трафика (эталонный клиент ClassicUO)

Сюда кладутся записи 8 сценариев Стадии 0 (вход, 20 шагов, речь, drag предмета, контейнер, гамп, прицел, смерть). Файлы только для чтения: по ним сверяются тесты и бот. Как записывать и сравнивать — [`docs/REFERENCE-CLIENT.md`](../docs/REFERENCE-CLIENT.md). Допустимые расхождения — `allowed-diffs.md` (появится с первой записью).

ClassicUO при записи настраивается на версию клиента 7.0.95.0 (`TARGET.md`) и читает те же файлы данных, что и сервер (ADR 0003). Имя файла: `NN-сценарий.log` (например, `01-login.log`). Логин и пароль в логах замаскировать.
