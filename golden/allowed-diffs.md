# Допустимые расхождения бота с эталонами ClassicUO

Эталоны — `golden/*.tsv` (записаны пользователем 14 ноября 2026, ClassicUO с GitHub, сборка 4 ноября 2025, версия клиента 7.0.95.0, копия сервера с пустым миром). Сравнение — `tools/golden/compare.sh`. Всё, чего нет в этом списке, — ошибка нашего клиента, пока не доказано обратное (`docs/REFERENCE-CLIENT.md` §5).

## Что совпадает (проверяет `compare.sh`)

| Сценарий | Проверка | Итог 14 ноября |
|---|---|---|
| 01-login | весь вход до 0x55 (LoginComplete), оба направления, номер и длина каждого пакета | клиент 6 пакетов, сервер 27 — совпадает |
| 03-speech | речь 0xAD и ответ сервера 0xAE — пакеты бота есть у ClassicUO в том же порядке и той же длины | совпадает; байты 0xAD отличаются только языком (ниже) |
| 05-container | двойной клик по рюкзаку 0x06, ответ 0x24 и 0x3C | совпадает (байты 0x06 и 0x24 одинаковые) |
| 07-target | `[add Bandage` (0xAD), прицел сервера 0x6C, ответ 0x6C, предмет 0xF3 | совпадает |
| 08-death | труп 0xF3, его содержимое 0x3C и вещи 0x89, статус смерти 0x2C, саван 0x2E | совпадает побайтно |

Записи 02-walk-20, 04-drag, 06-gump — образцы для Стадий 3 (движение), 5 (перенос предметов) и 6 (гампы); бот этого пока не умеет.

## Допустимые расхождения

| Пакет | Кто шлёт | Почему допустимо |
|---|---|---|
| 0x73 Ping | ClassicUO — раз в ~1 с, бот — раз в 10 с (`TARGET.md` §3.1) | сервер отвечает на каждый (`PingReq`) и отключает только после 30 с тишины; частота — дело клиента |
| 0xD1 Logout | только бот | ClassicUO при выходе просто закрывает соединение; бот шлёт 0xD1 и ждёт ответа — сервер его поддерживает (`IncomingPlayerPackets.cs`, `LogoutReq`) |
| 0xBF 0x0005 ScreenSize | только ClassicUO | сервер его не читает (`IncomingExtendedCommandPackets.cs`) — бот не шлёт |
| 0xBF 0x000F | только ClassicUO | сервер игнорирует (обработчик `Empty`) |
| 0xBF 0x000B Language | оба; ClassicUO — `IVL`, бот — `ENU` | язык клиента — умолчание 1.9 (`ClientLimits.Language`); ClassicUO с пустой настройкой `lang` шлёт `IVL`; тот же язык он ставит и в 0xAD |
| 0xBD ClientVersion | ClassicUO — дважды (ответ на запрос и ещё раз после входа), бот — один раз | сервер просит версию один раз; повтор ничего не меняет |
| 0xFB PublicHouseContent | только ClassicUO | сервер игнорирует (`IncomingHousePackets.cs`); дома — Стадия 8 |
| 0xB5 OpenChatWindow → 0xAE «The chat system has been disabled.» | только ClassicUO | чат на сервере выключен (`chat.enabled`); чат — Стадия 7 |
| 0xF0 0x01 QueryGuildLocations | только ClassicUO, раз в ~2,5 с | запрос мест гильдии для карты мира; гильдия — Стадия 7 (7.4) |
| 0x09 SingleClick, 0x34 MobileQuery и ответы 0x1C, 0x11, 0x3A, 0xBF 0x0019 | только ClassicUO | окно статуса, навыков и имя над собой — интерфейс эталонного клиента; бот спрашивает статус только когда нужно; навыки — 4.5, имена по клику — Стадия 5 |
| 0x06 со старшим битом (`80 00 00 01`) → 0x88 Paperdoll | только ClassicUO | кукла (выход из игры — через неё); старший бит в 0x06 — «показать куклу» (`IncomingPlayerPackets.cs`, `UseReq`); кукла — Стадия 5 |
| 0x72 WarModeRequest: ClassicUO `72 00 32 00 00`, бот `72 01 00 32 00` | оба | сервер читает только первый байт (`SetWarMode`: `ReadBoolean`); хвост бот пишет так же, как сервер свой ответ 0x72 |
| 0xBF 0x000C CloseStatus, 0xBF 0x0013 / 0x0014 ContextMenu, 0x02 / 0x22 шаги в 01, 06, 07 | только ClassicUO | действия человека в сценарии (закрыл окно, щёлкнул правой кнопкой, прошёл); 0xBF 0x0C сервер игнорирует |
| 0xAE «Welcome to Remaster UO.» и 0xA2 / 0xA3 (мана, выносливость) в другом месте и количестве | бот или ClassicUO | время: бот входит через секунды после создания персонажа (приветствие `WelcomeTimer` через 5 с после создания, мана ещё восстанавливается), а человек — через минуты |
| Позиции предметов в 0x3C, клетка в ответе 0x6C, серийники | оба | разные персонажи, место и время; длина и порядок совпадают |
