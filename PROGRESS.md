Запись сырого сжатого потока для сверки Huffman — вместе с остатком 1.3.
Первая часть закрыта: 1.1, 1.2, 1.4, 1.4а. Как собрана сеть: `TcpConnection` (фоновый поток: подключение, чтение → `ReceivePipeline`: Huffman → `PacketFramer` → `InboundQueue`) → `NetworkSession` (порт `INetworkSession`: `PacketDispatcher` по номеру, `OutgoingBuffer`) → `GameClient.Tick(now)` (бюджет 5 мс, одна отправка за тик). Обработчик пакета регистрируется в `PacketDispatcher` (`Register(id, …)` или `Register(id, подкоманда, …)`), исходящий пакет пишется через `PacketWriter` в `NetworkSession.Outgoing.Reserve/Commit`. Сжатие на игровом сокете включается `IConnection.EnableCompression()` до отправки 0x91 (задача 1.7); для 4 байт ключа перед 0x91 в `OutgoingBuffer` понадобится запись без проверки по матрице — добавить в 1.7.
Решения по сетевому ядру (пределы, дамп, бюджет тика, таймаут, очередь, порты, неизвестная подкоманда — дисконнект) — [ADR 0013](docs/adr/0013-network-core.md); значения — `TARGET.md` §3.1 и `ClientLimits`.
Шаг 2 закрыт: 0.4 (матрица `docs/protocol/packets.csv`), 0.5 (таблица `Network/Framing/PacketTable.g.cs`), 0.8 (`docs/LICENSES.md`). Новый пакет: строка в CSV → `python3 tools/gen/packet_table.py` → `tools/check/all.sh`.
