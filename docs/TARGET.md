# TARGET — цель клиента и сервера

Единственный источник конкретных значений протокола и правил. Код клиента берёт их из одного класса (`ServerLimits`/`ClientConfig`), этот файл — их документ. Меняется только через ADR.

*Обновлено 10 ноября 2026 (второй аудит). Каждая строка проверена по исходникам `server/ModernUO`; где искать — [`SERVER-MAP.md`](SERVER-MAP.md). Полный список пакетов появится в `protocol/packets.csv` (задача 0.4); эта страница — только то, что зависит от версии и эры.*

## 1. Клиент и эра

| Параметр | Значение | Где на сервере |
|---|---|---|
| Версия клиента | **7.0.95.0** | клиент шлёт в 0xEF и 0xBD; сервер выводит из неё `ProtocolChanges` |
| Тип клиента | Classic | `clientVerification.allowedClientTypes` (Classic, SA) |
| Эра правил | **Renaissance (UOR)**, `Id: 2` | `Distribution/Configuration/expansion.json` |
| Карты | **только Фелукка** (карта 0, 7168×4096) | `expansion.json` → `MapSelectionFlags`; размеры в `Distribution/Data/map-definitions.json` |
| Версия статуса 0x11 | 3 | `expansion.json` → `MobileStatusVersion` |
| Шифрование | не используется клиентом; сервер по умолчанию `Both` | `network.encryptionMode` (не задан) |
| Ориентир по стилю | The Abyss и подобные русские pre-AoS шарды | [ADR 0002](adr/0002-client-version-and-era.md) |
| Файлы данных | полная установка классического клиента UO в формате UOP; версия файлов может быть новее 7.0.95.0 | [ADR 0003](adr/0003-world-data.md) |
| Имена | UTF-8 (наше расширение E1) | [`protocol/extensions.md`](protocol/extensions.md) |

Версия протокола и эра в ModernUO независимы: формат пакетов определяется версией клиента, правила игры — эрой.

## 2. Пакеты, которые реально шлёт сервер для 7.0.95.0

| Тема | Пакет | Не используется |
|---|---|---|
| Мобы | 0x78 (новый формат, `NewMobileIncoming`), 0x20, 0x77 | 0xD3, 0xD2 |
| Предметы в мире | 0xF3 (`StygianAbyss` + HighSeas-формат) | 0x1A |
| Список персонажей | 0xA9 новый формат, 0x86 | — |
| Создание персонажа | 0xF8 (106 байт) | 0x00 |
| Статус | 0x11 версии 3 | — |
| Урон | 0x0B (в UOR по умолчанию не шлётся: `visibleDamage` = false) | 0xBF 0x22 |
| Перенос предмета | 0x07 → 0x08 (**15 байт**, с позицией в сетке) | 14-байтный 0x08 |
| Содержимое контейнера | 0x3C, 0x25, 0x74 — 20 байт на предмет (с сеткой) | 19-байтный формат |
| Открытие контейнера | 0x24 — **9 байт** (serial, gump, ещё 2 байта `0x007D`) | 7-байтный 0x24 |
| Книга заклинаний | 0x24 с gump 0xFFFF, затем содержимое **обычным 0x3C**: по «предмету» на заклинание (serial `0x7FFFFFFF − i`, количество = номер заклинания) | 0xBF 0x1B (сервер шлёт его только при `Core.AOS`) |
| Запрос размещения multi | 0x99 — **30 байт** | 26-байтный 0x99 |
| Гампы | 0xDD (сжатый) | 0xB0 |
| Торговля | 0x6F новый формат | — |
| Имена по клику | 0x1C ASCII (`asciiClickMessage` = true) | тултипы 0xD6/0xDC/0xBF 0x10 (`opl.enable` = false) |
| Крафт | меню 0x7C / 0x7D (`t2aCraftMenus` = true) | крафт-гампы |
| Корабли | обычные обновления предметов и мобов | 0xF6 (только при HS), 0xF7 |
| RTT-проба | сервер шлёт 0xBD во время ходьбы, клиент отвечает 0xBD | — |
| Позиции группы | 0xF0 подкоманда 0x00 (гильдия — 0x01), сервер отвечает на запрос клиента | — |
| Принудительный шаг | 0x97 (сервер двигает персонажа) | — |
| Окно куклы | 0x88 в ответ на двойной клик по себе или по мобу | — |

**Что эра UOR включает и выключает** (проверено по коду):

| Возможность | В UOR | Откуда |
|---|---|---|
| Оглушение и обезоруживание (0xBF 0x09, 0x0A) | **работают** только в UOR и раньше AoS | `Items/Weapons/Fists.cs` |
| Каст 0xBF 0x1C | работает в любой эре | `IncomingExtendedCommandPackets.CastSpell` |
| Контекстные меню (0xBF 0x13 → 0x14 → 0x15) | работают в любой эре | `Context Menus/ContextMenuSystem.cs` |
| Кнопка гильдии на кукле (0xD7 0x28) | **ничего не делает**: новая система гильдий только с SE; гильдии — через камень гильдии и гампы | `Misc/Guild.cs` (`NewGuildSystem => Core.SE`) |
| Кнопка квестов (0xD7 0x32) | квестов ML нет (`questSystem.enableMLQuests` = False) | `modernuo.json` |
| Крафт | меню 0x7C / 0x7D | `t2aCraftMenus` (по умолчанию включён до UOTD) |
| Тултипы, баффы, спецприёмы оружия, конструктор домов, плавный ход кораблей, золото на счёте | выключены | `ExpansionConfiguration.cs`, `expansion.json` |

## 4. Правила создания персонажа (ванильные, UOR)

- Статы: сумма **90** (для клиентов 7.0.16+), каждый 10–60.
- Навыки: каждый ≤ 50, сумма **100 или 120**, без повторов; некромантия, рыцарство, бусидо, ниндзюцу и др. в UOR недоступны (сервер обнуляет).
- Стартовый город — выбор из списка сервера (только Фелукка).
