# TARGET — цель клиента и сервера

Единственный источник конкретных значений протокола и правил. Код клиента берёт их из одного класса `ServerLimits`, этот файл — их документ. Меняется только через ADR.

*Обновлено 13 ноября 2026 (задачи 1.8–1.15: флаги карт клиента, правила создания персонажа, значения сессии — [ADR 0016](adr/0016-login-and-session.md)). Ранее — 12 ноября 2026 (задачи 1.12, 1.15: §3.1 — лог пакетов и бот; §5 — ручной список исключений и молчаливое подключение). Каждая строка проверена по исходникам `server/ModernUO`; где искать — [`SERVER-MAP.md`](SERVER-MAP.md). Список пакетов с длинами и статусами — [`protocol/packets.csv`](protocol/packets.csv); эта страница — версия, эра, лимиты и стенд.*

## 2. Пакеты и эра

Какие пакеты сервер шлёт и принимает для 7.0.95.0, их длины, зависимость от версии клиента и что из этого нужно клиенту — [`protocol/packets.csv`](protocol/packets.csv) (столбцы `server` и `status`; как читать — [`protocol/packets.md`](protocol/packets.md)).

**Что эра UOR включает и выключает** (проверено по коду):

| Возможность | В UOR | Откуда |
|---|---|---|
| Оглушение и обезоруживание (0xBF 0x09, 0x0A) | **работают** только в UOR и раньше AoS | `Items/Weapons/Fists.cs` |
| Каст 0xBF 0x1C | работает в любой эре | `IncomingExtendedCommandPackets.CastSpell` |
| Контекстные меню (0xBF 0x13 → 0x14 → 0x15) | работают в любой эре | `Context Menus/ContextMenuSystem.cs` |
| Кнопка гильдии на кукле (0xD7 0x28) | **ничего не делает**: новая система гильдий только с SE; гильдии — через камень гильдии и гампы | `Misc/Guild.cs` (`NewGuildSystem => Core.SE`) |
| Кнопка квестов (0xD7 0x32) | квестов ML нет (`questSystem.enableMLQuests` = False) | `modernuo.json` |
| Крафт | меню 0x7C / 0x7D | `t2aCraftMenus` (по умолчанию включён до UOTD) |
| Тултипы, баффы, спецприёмы оружия, конструктор домов, плавный ход кораблей, золото на счёте | выключены | `ExpansionConfiguration.cs`, `expansion.json` |
| Школы магии, кроме Magery (некромантия, рыцарство, бусидо, ниндзюцу, spellweaving, mysticism) | регистрируются только с AoS и позже | `UOContent/Spells/Initializer.cs` (`Core.AOS`, `Core.SE`, `Core.ML`, `Core.SA`) |
| Гаргульи, полёт (0xBF 0x32), смена расы (0xBF 0x2A) | эра SA — не реализуем | `IncomingExtendedCommandPackets.cs` |

### 3.1. Настройки клиента

Значения самого клиента, которых нет на сервере ([ADR 0013](adr/0013-network-core.md)). В коде — класс `ClientLimits`; предел длины пакета — `PacketInfo.MaxLength`.

| Что | Значение | Почему |
|---|---|---|
| Самый длинный пакет от сервера | 65 535 байт | столько вмещает поле длины (2 байта); отдельного предела у сервера нет (`PacketUtilities.cs`, `WritePacketLength`). Меньше заголовка (3 байта, у 0xBF — 5, у 0xF0 — 4) — ошибка |
| Дамп при ошибке нарезки | весь пакет; если длина неизвестна — до 256 байт с места ошибки | хватает, чтобы понять, что пришло, и лог не раздувается |
| Очередь пакетов от сокета к главному потоку | 2 МБ | как `network.sendBufferMaxSize` сервера (`NetState.Network.cs`): полная очередь останавливает чтение сокета, и сервер сам отключает клиента |
| Бюджет тика на разбор пакетов | 5 мс, но не меньше одного пакета за тик | треть кадра при 60 FPS; очередь движется, даже если пакет обрабатывается дольше |
| Таймаут подключения | 10 с | дольше сервер на локальном и обычном стенде не отвечает только при сбое |
| Предел файла лога пакетов | 64 МБ (`ClientLimits.PacketLogMaxChars`) | сессия входа — килобайты, часы в мире — единицы МБ; дальше запись останавливается строкой `#truncated`, файл на части не делится: одна сессия — один файл для фейкового сервера |
| Язык клиента (0xBF 0x0B после входа в мир) | ENU (`ClientLimits.Language`) | как у классического клиента по умолчанию; сервер пишет его в `Mobile.Language`, тексты cliloc выбирает сам клиент |
| Ping в мире (0x73) | раз в 10 с (`ClientLimits.PingIntervalMs`) | сервер отключает после 30 с без обмена данными (`NetState.Network.cs`: `NextActivityCheck`; `NetState.cs`, `CheckAlive`); треть предела переживёт два потерянных ping; после 0.6 — сверить с ClassicUO |
| Ожидание ответа на выход (0xD1) | 5 с (`ClientLimits.LogoutTimeoutMs`) | дальше клиент закрывает соединение сам |
| Ожидание ответа сервера во время входа | 30 с (`ClientLimits.ServerResponseTimeoutMs`) | список шардов, редирект, список персонажей, вход и загрузка мира; дальше — ошибка `Timeout`, клиент не ждёт молча; пока выбирает человек — не считается |
| Повтор входа (не подключились, разрыв в мире) | паузы 1, 2, 4, 8, 16 с — 5 попыток, затем ошибка (`ClientLimits.ReconnectDelaysMs`) | тем же шардом и персонажем; отказы сервера и ошибки протокола не повторяются; в боте — только с `--reconnect` |
| Бот: пауза между тиками | 16 мс (`BotRunner.TickIntervalMs`) | как кадр Unity при 60 FPS |
| Бот: файлов лога пакетов | 20 последних (`PacketLogFiles.KeepCount`) | `Logs/packets/`, не в git; старые бот удаляет сам |

## 4. Правила создания персонажа (ванильные, UOR)

- Имя: после обрезки пробелов по краям 2–24 символа, не больше 29 байт UTF-8, только буквы, пробел, дефис и апостроф (`NameVerification.cs`, `ValidatePlayerName`); иначе сервер молча назовёт персонажа «Generic Player».
- Статы: сумма **90** (для клиентов 7.0.16+), каждый 10–60.
- Навыки: **4** (клиенты 7.0.16+), каждый ≤ 50, сумма **100 или 120**, без повторов. Выбрать можно номера 0–46 (Alchemy … Meditation) и Mysticism (55): Stealth, RemoveTrap и Spellweaving сервер при создании не принимает, некромантию, Focus, рыцарство (до AoS), бусидо, ниндзюцу (до SE), Imbuing и Throwing (до SA) обнуляет (`CharacterCreation.cs`, `ValidateSkills`).
- Неверный выбор сервер не отвергает, а молча портит (статы 10/10/10, навыки пропадают, имя «Generic Player»), поэтому клиент такое не отправляет (`Core/Session/CharacterCreationRules`).
- Стартовый город — выбор из списка сервера (только Фелукка).

## 5. Стенд

| Настройка | dev-стенд (сейчас) | parity-стенд (для критериев стадий) |
|---|---|---|
| Данные `Data/ClientData` | **заглушка** (карты-копии, ~300 статиков, пустой multi) | полная установка классического клиента UO ([ADR 0003](adr/0003-world-data.md)); версия файлов: *пока не установлены* |
| `theverge.sandbox.enable` | False | False |
| `speedhack_detection` | **True** | True |
| `clientVerification.invalidClientResponse` | Warn | Kick |
| `serverListing.address` / `autoDetect` | 127.0.0.1 / False | 127.0.0.1 / False |
| Аккаунты | GM и игрок | GM (подготовка сцены) и игрок (тесты движения и боя) |
| Аккаунтов с одного адреса (`accountHandler.maxAccountsPerIP`) | 10: бот, тестовые аккаунты и нагрузочные проверки входят с 127.0.0.1 | 10 (решить перед нагрузочным тестированием) |
| Ручной список исключений (`ip-allowlist.json`, `ip-allowlist-theverge.txt`) | включён: 127.0.0.1 | выключен |

**Молчаливое подключение.** Подключение, которое 5 с ничего не прислало, сервер считает атакой и блокирует адрес на 15 минут (`NetState.Network.cs`, `DisconnectUnattachedSockets` → `BanReasons.SilentConnect` → `AutoDenylist`, `auto-denylist.json`; для 127.0.0.1 исключения нет). Тогда на стенд не войти ни боту, ни ClassicUO. Поэтому на dev-стенде 127.0.0.1 — в ручном списке исключений (`ManualAllowlist`), а бот не держит соединение молча (PLAN Стадия 1, риски).

Конфигурация сервера (`Distribution/Configuration/`) не хранится в git. Шаблон наших настроек — `Distribution/ConfigurationTemplates/theverge/` (в git). Копия до изменений 10 ноября — `Distribution/Configuration/backup-2026-11-10/`.
