## 2. Существенные проблемы

- **Факты протокола внутри правил агента** (длины, скорости, sequence, версия `7.0.95.0`). По плану версия выбирается в Стадии 0 в `TARGET.md`. Кроме того, указаны только скорости пешком, без верховых. → Перенесено в `TARGET.md` / `ServerLimits`, в AGENTS.md только ссылка.
- **Многопоточность**: разбор пакетов в фоновом потоке в DTO + `IMainThreadDispatcher`. Это даёт аллокации и сложность. План требует разбор в главном потоке с бюджетом на кадр. → Фоновый поток только читает, распаковывает и режет; разбор — в `GameClient.Tick`, одинаково в Unity и в боте.
- **`LocalWorldSimulator` (687 строк) и `ModernUOLoopbackServer` (645 строк)** дублируют серверную логику на клиенте. Это прямо противоречит авторитету сервера и быстро расходится с ModernUO. → Заменить «фейковым сервером», который проигрывает записанные golden-логи (так в плане Стадии 1).
- **Остатки 3D**: `DirectionToEulerY`, «3D-визуал экипировки», сортировка по оси `(0, 1, -0.26)`. В UO порядок отрисовки считается по X+Y, Z и приоритету. → Графика вынесена в Стадию 9 через ADR.
- **Гампы «современными префабами вместо серверной верстки»**: для сотен серверных гампов (крафт, банк, админка) это нереально. → Универсальный рендерер + необязательные «скины» по TypeID с тем же ответом `0xB1`.
- **Структура «Features/ — вертикальные срезы» и «слои Core/Network/Presentation» одновременно**, причём `Features/` пуст. → Одно правило: сначала слой (сборка), внутри домен с одинаковыми именами во всех слоях.
- **Presentation ссылается на Network** (`.asmdef`). UI может напрямую дёргать сеть. → Отдельная сборка `Bootstrap`; Presentation видит только Core, и компилятор не даст нарушить правило.
- **Нет правил по тестам, коммитам одной задачи, размеру diff, `.meta`/GUID, `FormerlySerializedAs`, ADR** — добавлено.
- **Лимиты слишком жёсткие и без исключений** (200 строк для таблицы Хаффмана, 2 уровня вложенности): агенты либо нарушают, либо дробят бессмысленно. → Две планки (цель / жёсткий предел) и явная пометка `size-exempt`.
- **Claude Code не читает AGENTS.md** — он читает `CLAUDE.md`. → Добавлен `CLAUDE.md` с `@AGENTS.md`.
- **Две копии одного файла** (`game-client/` и `The Verge/`) разойдутся. → Источник правды — `The Verge/AGENTS.md`; копию в `game-client` удалить или пометить архивной.
- **Неймспейс `Remaster.*` при названии проекта The Verge.**
