# Расширения протокола The Verge

Всё, чем наш протокол отличается от протокола ModernUO для клиента 7.0.95.0. Запись появляется **до** кода. Каждое расширение включается флагом при входе в мир; без флага клиент обязан работать с ванильным ModernUO.

| # | Расширение | Статус | Пакеты | Решение |
|---|---|---|---|---|
| E1 | Имена в UTF-8 | сервер готов, клиент — Стадия 1 | 0xF8 (приём), 0xA9/0x86, 0x98, 0x11 (отправка). Latin-1 остаётся в 0x1C, 0xAE, 0xC1, 0xCC, 0x6F, 0x9E, 0x7C | [ADR 0005](../adr/0005-utf8-names.md) |
| E2 | Facing — направление тела отдельно от движения (режим 3б) | запланировано, Стадия 3б | флаг при входе; новая подкоманда 0xBF «направление тела» (клиент → сервер); пакет рассылки `Facing` соседям | [ADR 0006](../adr/0006-facing-mode-3b.md) |

## Не расширения, но важно знать

- **Речевые команды `[minoc:...]`** — служебная песочница, не протокол. Выключена по умолчанию и доступна только GM ([ADR 0004](../adr/0004-sandbox-and-parity-stand.md)). Новый код клиента их не использует.
- **0xF0** (позиции группы и гильдии) — протокол ассистентов из ModernUO, не наше расширение.

## Шаблон записи

```
### E<N>. <Название>
- Флаг при входе: <как объявляется>
- Направление и id: <клиент → сервер / сервер → клиент>, <id или 0xBF sub>
- Поля: <имя: тип, порядок байт, длина>
- Поведение без флага: <что делает ванильный сервер / клиент>
- Тесты: <какие>
```
