# Расширения протокола The Verge

Всё, чем наш протокол отличается от протокола ModernUO для клиента 7.0.95.0. Запись появляется **до** кода. Без расширений клиент обязан работать с ванильным ModernUO.

| # | Расширение | Статус | Решение |
|---|---|---|---|
| E1 | Имена в UTF-8 | **сделано** на сервере и в клиенте (список персонажей 0xA9/0x86, создание 0xF8, выбор 0x5D); ботом проверено 13 ноября 2026: персонаж «Борис Жук» создан, найден в списке и вошёл в мир. Остальные пакеты с именами — Стадии 2 и 4 | [ADR 0005](../adr/0005-utf8-names.md) |
| E2 | Facing — направление тела отдельно от движения (режим 3б) | **отложено** до закрытия Стадий 0–8; кода нет | [ADR 0006](../adr/0006-facing-mode-3b.md) |

### E1. Имена в UTF-8
- Флаг при входе: нет. Действует для всех клиентов нашего сервера; ClassicUO покажет кириллицу мусором (осознанно).
- Что изменено: только кодировка имён, id и длины пакетов прежние.
- Поля фиксированной длины 30 байт (обрезка по байтам, не по символам; остаток — нули): имя в 0x1C, 0xAE, 0xC1, 0xCC, 0x6F, 0xA9/0x86, 0x98, 0x11, маджонг 0xDA.
- Строки с длиной впереди (длина считается **в байтах**): 0x9E, 0x7C, имя крафтера. **Известная ошибка:** размер самого пакета сервер пока считает по буквам — с кириллицей будет ошибка сервера; имя в кукле 0x88 осталось в Latin-1 (`TECH-DEBT.md` §3).
- От клиента в UTF-8: имя в 0xF8 (30 байт), новое имя в 0x75.
- Не тронуто (Latin-1/ASCII): *текст* сообщений 0x1C и аффиксов 0xC1/0xCC, логин, пароль, названия серверов. Кириллица в речи идёт Unicode-пакетами 0xAD/0xAE.
- Правило имени: любые буквы, 2–24 символа, не больше 29 байт UTF-8.
- Тесты: кириллическое имя проходит цикл «создать → список персонажей → войти → статус → речь → журнал» без искажений (Стадия 1 и 4).
- Файлы сервера: `docs/server-patches.md`.

### E2. Facing (отложено)
Описание появится здесь перед началом трека F (`PLAN.md`). Подход — ADR 0006.

## Не расширения, но важно знать

- **Речевые команды `[minoc:...]`** — служебная песочница, не протокол. Выключена по умолчанию и доступна только GM ([ADR 0004](../adr/0004-sandbox-and-parity-stand.md)). Новый код клиента их не использует.
- **0xF0** (позиции группы и гильдии) — протокол ассистентов из ModernUO, не наше расширение.
- **Версия клиента 7.0.95.0 при более новых файлах данных** — не расширение: версия протокола и версия файлов независимы ([ADR 0003](../adr/0003-world-data.md)).
