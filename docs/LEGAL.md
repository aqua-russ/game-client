# LEGAL.md — полный чеклист «чистоты» The Verge

**Цель:** к выпуску в проекте нет чужого контента (Ultima Online / EA), соблюдены лицензии (ModernUO — GPL-3.0), и это можно доказать проверкой, а не словами.
Причины решений — в [`LICENSES.md`](LICENSES.md) и [ADR 0014](adr/0014-own-assets-server-numbers.md). Это рабочий чеклист, не юридическое заключение; перед коммерческим запуском нужна консультация юриста по играм.

**Отложено до окончания переноса функционала** (решение пользователя, 14 ноября 2026): порядок работ — сначала весь функционал (Стадии 0–8), потом шлифовка и доработка, потом юридическая часть. До этого чеклист не выполняется, `tools/check/legal.sh` не запускается после задач и не входит в «готово»; открытые вопросы ниже ждут этого этапа.

## Как это проверяется

**Автоматически — одна команда:** `tools/check/legal.sh` (≈10 секунд). Печатает «ОК» или список ошибок.
- Без ключей — проверка «не стало хуже»: новые остатки UO/EA, новые совпадения с кодом сервера, файлы UO в git, пакет без записи о лицензии. Старые остатки только считаются и печатаются как прогресс.
- `tools/check/legal.sh --release` — проверка перед выпуском: **любой** остаток — ошибка.
- `tools/check/legal.sh --update-baseline` — зафиксировать текущее состояние как новую точку отсчёта (`tools/check/legal-baseline.json`). Делается только после осознанной замены, не чтобы «убрать красное».

**Когда запускает Claude:** с начала юридического этапа — после каждой задачи, которая трогает контент (тексты, названия, данные, ассеты, сервер, пакеты), и обязательно с `--release` перед любым выпуском или передачей сборки. Результат — в ответе по задаче, в блоке «Как проверить».

**Вручную (Claude делает по списку и пишет результат):** пункты, помеченные 👁 — их нельзя проверить скриптом; проверяю чтением файлов, реестра и скриншотов.

**Честные пределы.** Скрипт ловит слова из списка (`tools/check/legal.py`, `WORDS`), копии строк кода сервера и файлы UO в git. Он **не** докажет, что картинка, модель или звук «не похожи» на оригинал. Для них единственная проверка — реестр происхождения (раздел 5): у каждого ассета записан автор, источник и лицензия. Ассет без записи в реестре считается чужим.

## Открытые вопросы (нужно решение пользователя)

**A. Таблица Huffman скопирована из сервера.** `Assets/TheVerge/Network/Compression/HuffmanTree.cs`: таблица кодов (32 строки) совпадает с `Projects/Server/Network/NetworkCompression.cs`. Предложенное решение, исключающее риск полностью: клиент не содержит таблицы, а наш клиент и сервер сжимают трафик стандартным deflate из .NET (лучше сжатия UO); Huffman остаётся только в сервере для ClassicUO ([ADR 0018](adr/0018-deflate-instead-of-huffman.md), статус «предложено», ждёт «да»). Пока решение не выполнено, `legal.sh --release` падает на этом файле; после выполнения запись `copies` в `legal-baseline.json` удаляется.
