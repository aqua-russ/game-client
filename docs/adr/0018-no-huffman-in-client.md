# ADR 0018. Клиент не содержит таблицу Huffman: сервер не сжимает данные для нашего клиента

- **Статус:** предложено, 14 ноября 2026 (критерий пользователя: «решение должно исключить все риски»). Код не менялся; ждёт «да» пользователя.
- **Закрывает:** открытый вопрос A в [`LEGAL.md`](../LEGAL.md). **Уточняет:** `LICENSES.md` §1, [ADR 0013](0013-network-core.md) (сжатие Huffman на игровом сокете).

## Контекст
1. `Assets/TheVerge/Network/Compression/HuffmanTree.cs` содержит таблицу кодов Huffman (32 строки), совпадающую с `Projects/Server/Network/NetworkCompression.cs`. Это единственное найденное `tools/check/legal.sh` совпадение с кодом сервера (GPL-3.0), которое не является ложным.
2. Правило проекта: код ModernUO в клиент не переносится, чтобы клиент не стал производной работой под GPL (`LICENSES.md` §1).
3. Таблица нужна, только чтобы распаковывать данные, которые сервер сжимает. В самом сервере сжатие включается одной строкой и снабжено комментарием «Comment out these lines to turn off huffman compression» (`UOContent/Network/Packets/IncomingAccountPackets.cs`, `GameLogin`): отключение предусмотрено авторами ModernUO.

## Решение
Клиент The Verge не содержит таблицы Huffman и не умеет распаковывать Huffman вообще. Для нашего клиента сервер отправляет данные без сжатия.
1. **Сервер** (наш форк, файл в `UOContent`, а не ядро `Projects/Server`): настройка «сжатие Huffman» в конфигурации сервера, **по умолчанию выключено**. Включается только для сверок с ClassicUO (`REFERENCE-CLIENT.md`), который ожидает сжатый поток. Правка — строка в `docs/server-patches.md` и запись в `docs/protocol/extensions.md` (E3).
2. **Клиент:** удалить `HuffmanTree`, `HuffmanDecoder`, их тесты и `HuffmanTestEncoder`; `ReceivePipeline` принимает пакеты без распаковки; `NetworkSession.EnableCompression` и связанные вызовы убрать.
3. **Проверки:** тест-фикстуры без сжатия; `legal.sh` после правки не должен находить совпадений в `Network/Compression`; запись `copies` в `legal-baseline.json` удаляется.
4. **Позже, по желанию:** если трафик понадобится сжимать, берём стандартный алгоритм из библиотеки с проверенной лицензией (например, deflate из .NET) и описываем как расширение E4. Таблица UO для этого не нужна.

## Почему так, а не иначе
- **Оставить таблицу, записав «константы протокола».** Юридически аргумент разумный, но риск остаётся, а критерий пользователя — ноль.
- **Выписать таблицу заново «из спецификации».** Значения те же, независимость происхождения доказать нельзя: эта таблица у всех реализаций UO одна, а «чистая комната» невозможна, если результат обязан совпасть побайтно.
- **Выбрать GPL-3.0 для клиента.** Закрывает вопрос о заимствовании, но лишает права закрыть клиент и делает коммерческий выпуск зависимым от GPL.
- **Отключить сжатие** — единственный путь, при котором в клиенте нет ни копии, ни пересказа чужого кода.

## Последствия
- Больше трафика сервер → клиент. Для игры уровня UO (мелкие пакеты, десятки на игрока) это не критично; измерить на нагрузочном прогоне до выпуска.
- Сверки с ClassicUO требуют включить настройку на стенде сверки; бот и Unity-клиент работают с выключенной.
- Изменятся: `PLAN.md` Стадия 1 (пункт «Huffman», задача 3), `ADR 0013`, `AGENTS.md` (список `Network/Compression`), `TARGET.md`, `PROGRESS.md`.
- Запись реплеев и фикстур входа (`bot-login-modernuo.tsv`) придётся перезаписать ботом против сервера с выключенным сжатием.
