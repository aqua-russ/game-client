# ADR 0003. Данные мира: полные файлы клиента 7.0.95.0

- **Статус:** принято, 10 ноября 2026; **ожидает действия** — положить файлы

## Контекст
`server/ModernUO/Distribution/Data/ClientData` сейчас — заглушка для прототипа: `map0.mul` и `map1.mul` побайтно одинаковые (сгенерированы под часть пещеры Минока), статики ~2 КБ на весь мир, `multi.mul` пустой, других карт, Cliloc и прочих файлов нет. С такими данными Стадии 2, 3 и 8 непроверяемы, а дома и корабли невозможны.

## Решение
1. Для Стадий 0–8 используем **полные файлы данных классического клиента той же версии, что в `TARGET.md` (7.0.95.0)**. Файлы принадлежат EA: каждый разработчик и игрок использует свою установленную копию, в репозитории их нет.
2. Сервер: путь в `dataDirectories` файла `modernuo.json`. Клиент: путь в настройках клиента (`UoDataPaths`), тот же набор файлов.
3. Заглушку не удалять: перенести в `Data/ClientData-stub/` и использовать только для быстрых smoke-тестов.
4. Собственный мир и графика — отдельный трек после Стадии 8.

## Последствия
- Пока файлов нет, Стадия 2 ограничена разбором пакетов, а parity-проверки отложены.
- При смене версии клиента меняются и файлы; версия данных фиксируется в `TARGET.md`.
