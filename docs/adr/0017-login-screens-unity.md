# ADR 0017. Экраны входа в Unity: модель экранов в Core, Unity только показывает

- **Статус:** принято, 13 ноября 2026 (задача 1.16; умолчания агента записаны в `PROGRESS.md`, «Вопросы пользователю», и могут быть изменены)

## Контекст
Задача 1.16 — первая с интерфейсом. Тесты идут в `dotnet test` без Unity (ADR 0010), а сборка `Presentation` без Unity не собирается. Значит, всё, что можно проверить без Unity (какой экран показан, какая кнопка когда активна, тексты ошибок, переходы), должно жить в чистом C#. Новая сборка — только с ADR и согласием (`AGENTS.md` §2.1), поэтому модель экранов кладётся в существующую.

## Решение
1. **Модель экранов входа — в `Core/Session/Screens`** (`LoginScreens`, `LoginForm`, `CharacterList`, `CharacterForm`, тексты `LoginErrorText`, `LoginStatusText`). Она только вызывает `LoginFlow`, `CharacterSelection`, `GameSession`; решений о протоколе в ней нет. Тексты причин ошибок общие для Unity и бота (`LoginErrorText`).
2. **Unity только показывает.** Разметка — `UI/Session/LoginScreens.uxml` и `.uss` (ADR 0007); классы View в `Presentation/UI/Session` находят элементы по имени, передают нажатия в модель и перерисовываются, только когда растёт `LoginScreens.Revision` (кадр без изменений ничего не делает).
3. **Одно «Войти» — один клиент.** `Bootstrap/UnityLoginClient` собирает сеть, вход и ядро так же, как `BotClient`; повтор входа (`Reconnector`) в Unity включён всегда (ADR 0016 п. 6). Закончился вход (ошибка без повтора, выход, «Отмена») — клиент закрывается, следующее «Войти» собирает новый: так можно исправить пароль после отказа.
4. **Тик.** `GameBootstrap.Update` → `LoginScreens.Tick(now)` → `GameClient.Tick(now)` с бюджетом `ClientLimits.TickBudgetMs`, затем `LoginScreensView.Refresh`.
5. **Панель UI создаётся кодом** (`PanelSettings` в `GameBootstrap`); в сцене — только ссылки на разметку и тему `UI/TheVergeTheme.tss` (стандартная тема Unity, на ней держится вид полей и кнопок). Ссылки ставит меню «The Verge → Prepare Bootstrap Scene».
6. **Последний адрес сервера и логин** запоминаются в настройках Unity на этом компьютере (`PlayerPrefs`) при нажатии «Войти». **Пароль не сохраняется никогда** и не пишется ни в лог, ни в подсказки.

## Последствия
- Новые экраны других стадий (журнал, навыки, рюкзак) строятся так же: модель в Core рядом с доменом, тесты на неё, в Unity — разметка и тонкий View.
- Значение по умолчанию адреса — `ClientLimits.DefaultServerAddress` (`TARGET.md` §3.1).
- Шрифт с кириллицей и свой стиль интерфейса — Стадия 9 (графика); до неё — стандартная тема Unity.
