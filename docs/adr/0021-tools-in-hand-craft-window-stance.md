# ADR 0021. Инструменты в руке, кирка вместо лопаты, одно окно ремесла, боевая стойка только по `Esc`

- **Статус:** принято, 14 ноября 2026. Решения пользователя: инструменты в руке — обсуждено с Gemini и подтверждено пользователем; кирка вместо лопаты, одно окно ремесла и стойка только по `Esc` — по разбору кода сервера (Claude), ответ пользователя «да».
- **Отходит от:** оригинальных механик эры UOR ([ADR 0001](0001-no-gdd-port-original-mechanics.md)) — осознанно, ради управления одной кнопкой `F` ([`CONTROLS.md`](../CONTROLS.md) §4, §5.2). До правок на Стадиях 5 и 6 сервер работает как в оригинале; [`TARGET.md`](../TARGET.md) описывает текущее поведение сервера.
- **Уточняет:** `CONTROLS.md` §0, §4, §5.2; `PLAN.md` Стадия 4 (п. 7), Стадия 5 (пп. 4–5), Стадия 6 (п. 4).

## Контекст
1. **Слоты инструментов.** В оригинале в руку надеваются только молот кузнеца и кувалда (`SmithHammer`, `SledgeHammer`: `Layer.OneHanded` в конструкторе). Кирка — одноручное оружие, топор и удочка — двуручные (слой из tiledata и `FishingPole.cs`). У остальных инструментов ремесла (`BaseTool`) и у лопаты (`Shovel : BaseHarvestTool`) слота нет.
2. **Инструмент в руке сервер уже принимает.** `BaseTool.OnDoubleClick` и `BaseHarvestTool.OnDoubleClick` работают, если инструмент в рюкзаке *или* в руке; ремесло проверяет то же (`BaseTool.CheckAccessible`). `BaseTool.CheckTool` запрещает работать другим инструментом, пока в руке уже есть инструмент ремесла, — при правиле «`F` применяет то, что в руке» это не мешает.
3. **Лопата и кирка.** Копают одинаково (`Mining.System`: те же руда и шансы). Лопата легче (5 против 11) и не оружие; кирка — одноручное оружие, её чинит кузнец (`Repair.cs`). Клад по карте сокровищ сервер даёт копать только инструментом семейства `BaseHarvestTool` в рюкзаке (`TreasureMap.HasDiggingTool`), то есть лопатой: кирка для этой проверки — оружие.
4. **Окно ремесла.** В эре до UOTD по умолчанию работают старые меню 0x7C (`t2aCraftMenus` = `!Core.UOTD`, `ExpansionConfiguration.cs`; `dev-docs/t2a-crafting.md`): двойной клик по инструменту открывает прицел (в инструмент — «сделать последнее», в материал — меню), меню закрывается после каждой вещи, клеймо мастера спрашивается всегда, у писаря и картографа инструмента нет (`RequiresTool => !T2ACraftSystem.Enabled`). С `t2aCraftMenus = false` двойной клик сразу открывает окно `CraftGump` (0xDD / 0xB1): разделы, выбор металла, «Сделать последнее», «Последние 10», починка, переплавка, переключатель клейма; окно остаётся открытым. Правила эры (половина материалов при неудаче и др.) зависят от `Core.UOTD`, а не от вида окна.
5. **Боевая стойка.** Автовыход по таймеру придумывали ради стрел лучника, но сбор стрел вне стойки (`AmmoRecovery`) есть только с эры SE (`BaseRanged.OnMiss`, ветка `Core.SE`); в UOR промахнувшаяся стрела сразу падает на землю рядом с целью. Признак «врага нет» (0xAA = 0) ненадёжен: сервер ставит противника только при первом нападении нового агрессора (`Mobile.AggressiveAction`), поэтому если бьют двое и первый умер, приходит 0, хотя второй продолжает бить. В UOR стойка почти ничего не меняет: выход сбрасывает противника, призрак в стойке виден живым (`Mobile.Warmode`, `Mobile.CanSee`).

## Решение
1. **Инструменты в руке.** Все инструменты ремесла (`BaseTool`) надеваются в руку: `Layer.OneHanded`, как у `SmithHammer`. Кирка, топор и удочка остаются как в оригинале (кирка — одна рука, топор и удочка — обе). Старые инструменты из сохранённого мира получают слот при загрузке: слот сохраняется, только если задан (`Item.Serialize`), и без перевода они остались бы без слота.
2. **Кирка вместо лопаты.** Лопаты убираются из игры: продажа (`SBMiner`, `SBTinker`), ремесло жестянщика (`DefTinkering`, `TinkeringMenu`), добыча (`OrcishLord`), наполнители сундуков (`FillableContent`); квестовую лопату (`Uzeraan`) проверить при правке. Клад копается киркой — из рюкзака или из руки (`TreasureMap.HasDiggingTool`). Лопаты, которые уже есть в мире, копать продолжают — их не удаляем.
3. **Одно окно ремесла.** `t2aCraftMenus = false` в настройках стенда и в шаблоне `Distribution/ConfigurationTemplates/theverge/` (`AGENTS.md` §5.7). Меню 0x7C остаются для других списков выбора. Позже окно можно показать своим видом с теми же кнопками (`AGENTS.md` §4.3, «скин» по TypeID).
4. **Стойка только по `Esc`.** Клиент включает стойку сам при атаке (`Space`), выключает только принудительно: `Esc` (уровень 3; с 15 ноября 2026 в стойке он идёт сразу после прицела и окна не закрывает), метка «Бой: имя» или необязательная команда «Прекратить бой» ([ADR 0022](0022-mouse-camera-targeting.md), пп. 16, 19). Автовыхода по времени нет — подтверждено 15 ноября 2026: автосбор стрел SE не берём ([ADR 0024](0024-later-era-conveniences.md)), стрелы подбираются с земли.

## Последствия
- **Рука одна.** С инструментом в руке нельзя держать одноручное или двуручное оружие (`BaseWeapon.CheckConflictingLayer`, тот же слой), щит — можно. Перед боем инструмент снимают; автоснятие при атаке — отдельное решение позже.
- **Медитация и воровство.** С любым предметом в руке сервер эры UOR не даёт медитировать и воровать (`Meditation.CheckOkayHolding`, `Stealing.IsEmptyHanded`). Каст заклинаний руки не проверяет. *Изменено [ADR 0024](0024-later-era-conveniences.md), п. 15:* медитация сама убирает предмет из рук в рюкзак; воровство — по-прежнему с пустыми руками.
- **Где правится сервер.** Пп. 1–2 — Стадия 5 (задачи 5.4–5.5), п. 3 — Стадия 6 (задача 6.4): правки в `UOContent` с тестами и строками в `docs/server-patches.md`.
- **Писарь и картограф** с одним окном работают пером (`ScribesPen`, `MapmakersPen`) — по тому же правилу «инструмент в руке + `F`».
- **Окно большое** и показывает все предметы раздела, а не только доступные: нужны тексты (задача 4.1) и показ гампов (Стадия 6).
- **Задача 4.7:** таймера автовыхода в коде ещё нет — меняется только план (п. 7 Стадии 4).
