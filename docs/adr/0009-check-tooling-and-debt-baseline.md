# ADR 0009. Инструменты проверки: NUnit, python3, базовая линия долга прототипа

- **Статус:** принято, 11 ноября 2026 (задача 0.1, NUnit согласован с пользователем)

## Контекст
1. `AGENTS.md` §7 требует `dotnet test` и `tools/check/architecture.sh`. Тестовая библиотека — пакет NuGet, а пакеты добавляются только с согласия пользователя.
2. Код прототипа (~7 100 строк) уже нарушает правила размеров и именования (75 мест) и не размечен под nullable (115 предупреждений при включении). По `docs/TECH-DEBT.md` §1 он заменяется, а не переписывается. Без особого режима проверка была бы красной с первого дня и перестала бы что-то значить.
3. Старому окну статуса сети нужны счётчики пакетов, а ссылку `Presentation → Network` нужно снять (ADR 0008).

## Решение
1. **Тесты — NUnit 4** (`NUnit`, `NUnit3TestAdapter`, `Microsoft.NET.Test.Sdk`), только в `dotnet/TheVerge.Tests`. Тот же стиль тестов, что у Unity Test Framework. Tests и Bot — `net10.0`, `LangVersion 9.0`; Core, Network, Data — `netstandard2.1` (ADR 0008).
2. **Проверка архитектуры — python3 из стандартной библиотеки** (совместимо с 3.9, на Mac ставится с инструментами разработчика Xcode). Разбор C# грубый, без компилятора: ловит явные нарушения, а не все. Правило без скобок или экзотический синтаксис может проскочить.
3. **Базовая линия долга.** `tools/check/architecture-baseline.txt` (нарушения правил) и `tools/check/dotnet-warnings-baseline.txt` (предупреждения сборки) хранят известный долг прототипа. Проверка падает на новом нарушении и на росте старого. Строки только убираются (`architecture.sh --shrink-baseline`); добавлять — только с согласия пользователя.
4. **Nullable** включён на уровне сборки (ADR 0008). 12 файлов долга помечены первой строкой `#nullable disable` — пометка исчезает вместе с файлами. Остающийся код размечен по-настоящему (`Serial`, `Point3D`, `PlayerStatsModel`).
5. **Временный порт** `Core/Ports/INetworkDiagnostics` — только для старого окна статуса сети; уходит вместе с ним на Стадии 1.
6. `dotnet/Directory.Build.props` разводит `obj/` и `bin/` проектов, лежащих в одной папке.
7. Компиляция Unity — `tools/check/unity.sh` (только Mac, редактор закрыт); `tools/check/all.sh --unity` — всё вместе.

## Последствия
- `all.sh` зелёный на текущем коде; любое новое нарушение — красный.
- Агент не может «заглушить» проверку правкой базовой линии без согласия пользователя.
- Аудит прототипа (задача 0.9) уменьшает базовую линию; её размер — мера оставшегося долга.
