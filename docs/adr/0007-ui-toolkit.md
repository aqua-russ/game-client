# ADR 0007. UI клиента на UI Toolkit (UXML/USS)

- **Статус:** принято, 10 ноября 2026

## Контекст
Агент не может надёжно собирать uGUI-префабы, поэтому правило «UI только префабами» обходилось сборкой интерфейса из C#. UI Toolkit хранит разметку текстом (UXML/USS): её удобно писать, проверять в diff и использовать для универсального рендерера гампов.

## Решение
Окна и HUD — UI Toolkit (runtime, `UIDocument`), разметка в `Assets/TheVerge/UI/<Domain>/`. Мир (тайлы, мобы, предметы) рисуется не через UI, а объектами сцены (с 13 ноября 2026 — 3D-сцены, [ADR 0015](0015-3d-client.md)). Существующий uGUI-код прототипа (экраны входа и создания персонажа, HUD) — долг: переписывается при касании. Новый UI на uGUI не пишем.
