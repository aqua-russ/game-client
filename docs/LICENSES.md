# Лицензии: что и как мы используем из чужих проектов

Чьи программы, код и файлы участвуют в проекте, под какой лицензией и что из этого следует для нас. Проверено 11 ноября 2026 по самим файлам лицензий. Это рабочая памятка разработки, а не юридическая консультация.

**Решение:** код клиента (Core, Network, Data и остальное) пишем заново. Исходник сервера ModernUO читаем как справочник, ClassicUO запускаем только как эталон для сверки. Код из них в клиент не переносится.

## 1. ModernUO — GPL-3.0

- **Клиент — отдельная программа.** Он общается с сервером только по сетевому протоколу UO и не содержит кода сервера. Поэтому GPL сервера не распространяется на клиент, пока мы **не копируем** в клиент ни кода, ни его частей (таблиц, алгоритмов в виде кода). Это правило уже в `AGENTS.md` §1 п. 4. Скопированный код сделал бы клиент производной работой, и его пришлось бы открывать под GPL.
- **Как читаем.** Формат пакетов, правила и значения сверяем по исходнику и записываем своими словами в документы, тесты и собственный код. Путь к месту на сервере пишем в комментарии (`AGENTS.md` §3.4) — это ссылка, а не копия.
- **Наш форк сервера** — производная работа от ModernUO и остаётся под GPL-3.0: файл `LICENSE` и заголовки файлов не удаляем, наши правки (`server-patches.md`) — тоже GPL-3.0. Если когда-нибудь отдавать сборку сервера другим людям, вместе с ней нужно дать и исходники. Запуск сервера для игроков этого не требует: это GPL, а не AGPL.

## 2. ClassicUO — BSD 2-Clause

- Источники расходятся: README ClassicUO называет лицензию «BSD 4», боковая панель GitHub — «BSD-2-Clause». Главный — файл `LICENSE.md` в корне репозитория: в нём два условия (сохранять уведомление об авторских правах в исходниках и в документации к сборкам) и отказ от гарантий, то есть BSD 2-Clause. Запись в README устарела.
- Лицензия разрешила бы брать код с уведомлением об авторстве, но мы **не берём** код ClassicUO по своему решению: клиент сверяется с сервером, и чужой код принёс бы чужие допущения о протоколе (`REFERENCE-CLIENT.md` §1). ClassicUO в репозиторий не кладём и не распространяем — ставится отдельно с его страницы релизов.

## 3. Файлы данных Ultima Online — Electronic Arts

- EA User Agreement (раздел 2 «License») даёт пользователю личную, ограниченную, непередаваемую и отзывную лицензию для некоммерческого использования и запрещает копировать, изменять и распространять содержимое EA без разрешения EA или закона.
- **Поэтому:** файлы данных (`*.mul`, `*.uop`) не попадают в git (уже в `.gitignore`) и не распространяются вместе с клиентом. Каждый, кто запускает клиент или сервер, сам ставит официальный клиент UO с uo.com, и обе программы читают его папку (ADR 0003, `REFERENCE-CLIENT.md` §2).
- **Риск на будущее:** для открытого или коммерческого выпуска игры нужна собственная графика и данные мира, а не файлы EA. Решать при планировании Стадии 9 (графика) и выпуска.

Новый пакет добавляется только с согласия пользователя (`AGENTS.md` §6), и его лицензия записывается сюда.

## Открытый вопрос

Лицензия самого клиента The Verge не выбрана. Решение пользователя — когда понадобится открывать или выпускать клиент; ограничения выше (без кода ModernUO, без файлов EA) позволяют выбрать любую.
